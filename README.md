# Password Strength Checker

A beginner-friendly Python cybersecurity project that checks the strength of a password based on common security requirements.

## Features

 Checks password length
 Checks for uppercase letters
 Checks for lowercase letters
 Checks for numbers
 Checks for special characters
 Detects some common weak passwords
 Classifies passwords as Weak, Medium, or Strong
Demonstrates password hashing using SHA-256

## Technologies Used

 Python
 Regular Expressions (Regex)
 hashlib
 getpass
